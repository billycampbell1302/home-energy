📶 Router

One-off: on the iPad, open your router's admin page (usually 192.168.1.1), log in, then go to System → Scheduled Tasks, paste this line on a new line, and tap Save. Then System → Startup, find cron and tap Restart.

✓ Connected

The email and password you use for the ConnectLife app.

📍 Location

Free app, no account, sends the phone's location only to this server. On each iPhone: install OwnTracks from the App Store → tap (i) → Settings: Mode HTTP, URL = that person's link below (leave user/password empty) → back on the map, set the monitoring mode (top-left icon) to Significant (low battery). Allow location Always when asked.

📲 Arrive/leave shortcuts

On each iPhone: Shortcuts app → Automation → + → Arrive → choose Home → Run Immediately → add action Get Contents of URL → paste the Arrive link. Repeat with Leave and the Leave link.

🛏️ Bedtime (Sleep Focus)

Tells the app exactly when you go to sleep and get up, so the heating stays on until bedtime and is warm when you're up. Set up once on each adult's iPhone:

  1. Shortcuts app → Automation → + → Sleep (under Focus) → When Turning On → Run Immediately → Next
  2. New Blank Automation → add action Get Contents of URL → paste that person's ON link below → Done
  3. Do it again choosing When Turning Off with the OFF link

Sleep Focus switches on with your iPhone's sleep schedule (Health app → Sleep), or tap it in Control Centre at bedtime.
